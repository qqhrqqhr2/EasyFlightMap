# Easy Flight Map

[English guide](docs/USER_GUIDE-enUS.md) · [한국어 설명서](docs/USER_GUIDE-koKR.md)

## English

A dedicated flight map showing destinations, fares, and travel times, with animated route highlighting and optional confirmation before flying.

Talk to a flight master to open the map. Use `/efm config` for settings. Korean clients use Korean UI; other client languages use English. Destination names come from the game client.

This package targets interface version 16001.

## 한국어

목적지·요금·소요 시간을 한눈에 확인하고, 마우스를 올리면 경로를 강조하는 전용 비행 지도입니다. 비행 전 확인 창을 선택적으로 사용할 수 있습니다.

비행 조련사와 대화하면 지도가 열립니다. `/efm config`로 설정을 엽니다. 한국어 클라이언트에서는 한국어, 그 외 언어에서는 영어 UI를 표시합니다. 목적지 이름은 게임 클라이언트가 제공한 이름을 사용합니다.

인터페이스 버전 16001을 대상으로 합니다.
