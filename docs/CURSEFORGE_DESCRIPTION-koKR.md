# Easy Flight Map

**목적지와 요금, 비행 시간을 한눈에 확인하는 전용 비행 지도입니다.**

비행 조련사와 대화하면 깔끔한 지도 창이 열립니다. 목적지 이름·지역·요금·소요 시간을 지도 위에서 확인하고, 원하는 목적지에 마우스를 올려 비행 경로를 살펴보세요.

## 주요 기능

- **항상 보이는 목적지 정보** — 이름표에 목적지, 지역, 요금과 비행 시간을 함께 표시합니다. 요금은 금화·은화·동화 아이콘으로 구분합니다.
- **움직이는 경로 강조** — 목적지에 마우스를 올리면 선택 지점과 이름표가 밝아지고, 연결선과 비행 경로를 강조합니다. 경로 위로 빛이 움직여 이동 방향을 보여줍니다.
- **지도 안쪽 이름표** — 비행 지점과 겹치지 않도록 이름표 위치를 조정합니다. 기본 설정은 지도를 전체 표시합니다.
- **비행 시간 기록** — 완주한 경로의 실제 시간을 저장합니다. 기록이 없는 경로는 구간 거리 정보가 있을 때 예상 시간을 표시합니다.
- **비행 전 확인** — 설정에서 확인 창을 켜면 목적지·요금·시간을 확인한 뒤 비행할 수 있습니다.
- **남은 시간과 도착 알림** — 비행 중 남은 시간 막대와 도착 알림을 사용할 수 있습니다.
- **표시 설정** — 창 크기, 투명도, 글자 크기, 이름표, 미발견·미연결 지점 표시를 조절할 수 있습니다.
- **한국어·영어 지원** — 한국어 클라이언트에서는 한국어, 그 외 언어에서는 영어 UI를 표시합니다. 목적지 이름은 게임 클라이언트가 제공한 이름을 사용합니다.

## 사용 방법

1. 애드온을 설치하고 비행 조련사와 대화합니다.
2. 이름표에서 요금과 시간을 확인합니다.
3. 목적지 지점 또는 이름표에 마우스를 올려 경로를 확인합니다.
4. 목적지를 클릭하면 비행합니다. 확인 창을 사용하려면 `/efm config`에서 **비행 전 확인 창 표시**를 켜세요.

창을 드래그하면 위치를 바꿀 수 있고, **Ctrl + 마우스 휠**로 크기를 조절할 수 있습니다. 비행 조련사 대화창을 건너뛰는 설정이 켜져 있어도 **Shift를 누른 채 대화**하면 대화창을 볼 수 있습니다.

## 시간과 경로 표시 안내

- **약 …**: 거리와 비행 속도를 바탕으로 계산한 예상 시간입니다. 실제 비행 시간과 차이가 날 수 있습니다.
- **미측정**: 실제 기록과 계산에 필요한 구간 정보가 없습니다.
- **미확인**: 게임에서 요금을 확인할 수 없습니다.
- **비행 경로 미발견**: 아직 발견하지 않은 것으로 게임에서 확인된 지점입니다.
- **연결된 비행 경로 없음**: 현재 위치에서 연결된 경로를 확인할 수 없는 지점입니다.

비행 시간은 정상적으로 도착한 경로를 기준으로 기록하며, 조기 하차한 비행은 기록에 반영하지 않습니다. 목적지가 밀집해 이름표를 배치할 공간이 부족한 경우 지점에 마우스를 올려 정보를 확인할 수 있습니다.

## 호환성

현재 배포 파일의 인터페이스 버전은 **16001**입니다. 다른 게임 클라이언트 버전에서의 호환성을 보장하지 않습니다.
