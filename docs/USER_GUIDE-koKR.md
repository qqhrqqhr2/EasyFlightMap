# Easy Flight Map 사용 설명서

버전: 0.5.2

## 설치

1. 배포 ZIP을 압축 해제합니다.
2. `EasyFlightMap` 폴더를 게임 설치 경로의 `Interface/AddOns` 폴더에 넣습니다.
3. `Interface/AddOns/EasyFlightMap/EasyFlightMap.toc` 파일이 있는지 확인합니다. 같은 이름의 폴더가 두 번 중첩되지 않도록 주의하세요.
4. 게임을 재시작하고 캐릭터 선택 화면에서 애드온을 활성화합니다.

이 설명서는 인터페이스 버전 16001을 대상으로 한 배포 파일 기준입니다.

## 지원 언어

한국어 클라이언트(`koKR`)에서는 한국어 UI를 사용하며, 그 외 언어에서는 영어 UI를 사용합니다. 목적지와 지역 이름은 게임 클라이언트가 제공한 이름을 표시하며, 애드온이 별도로 번역하지 않습니다. 소개글과 사용 설명서는 한국어·영어 문서로 제공합니다.

## 지도 열기와 비행

비행 조련사와 대화하면 전용 지도가 열립니다. 기본 설정에서는 조련사 대화창을 건너뜁니다. 대화창이 필요하면 Shift를 누른 상태에서 말을 거세요.

목적지 이름표에는 목적지와 지역, 요금과 시간이 표시됩니다. 목적지 지점이나 이름표에 마우스를 올리면 선택 지점, 이름표와 연결선이 강조됩니다. 확인된 비행 경로에는 금색 선과 움직이는 빛이 표시됩니다.

비행 가능한 목적지를 클릭하면 비행합니다. `/efm config`에서 **비행 전 확인 창 표시**를 켜면 클릭 후 목적지·요금·시간을 확인하고 **비행** 버튼을 눌러 출발합니다. 기본 설정에서는 확인 창이 꺼져 있습니다. 확인 중 요금이 변경되면 갱신된 요금을 다시 확인해야 합니다.

## 요금과 시간 읽기

| 표시 | 의미 |
| --- | --- |
| 금화·은화·동화 아이콘과 숫자 | 게임에서 확인한 현재 비행 요금 |
| 무료 | 비행 가능한 경로에서 확인된 요금이 0인 경우 |
| 미확인 | 현재 요금을 확인할 수 없는 경우 |
| 약 1분 30초 같은 표시 | 구간 거리와 비행 속도로 계산한 예상 시간 |
| 약 표시가 없는 시간 | 해당 경로를 완주하며 기록한 실제 비행 시간 |
| 미측정 | 실제 기록과 예상 계산에 필요한 구간 정보가 없는 경우 |
| 비행 경로 미발견 | 게임에서 미발견 상태로 확인한 지점 |
| 연결된 비행 경로 없음 | 현재 위치에서 연결 경로를 확인할 수 없는 지점 |

예상 시간은 실제 시간과 차이가 있을 수 있습니다. 정상적으로 도착하면 경로별 실제 시간을 저장하며, 조기 하차는 기록과 속도 학습에서 제외합니다. 요금이나 시간이 확인되지 않는 지점을 무료 또는 0초로 간주하지 않습니다.

## 화면 조작

- **창 드래그**: 지도 창 이동.
- **Ctrl + 마우스 휠**: 지도 창 크기 조절.
- **남은 시간 막대 드래그**: 막대 위치 이동.
- **기본 비행 지도로 보기**: 게임 기본 비행 지도로 전환.

이름표는 지도 안쪽에 배치하며 비행 지점과의 겹침을 피합니다. 지점이 밀집해 공간이 부족하면 일부 이름표가 숨겨질 수 있습니다. 이 경우 해당 지점에 마우스를 올려 정보를 확인하세요.

## 설정

채팅창에 `/efm config` 또는 `/비행지도 설정`을 입력합니다.

| 설정 | 용도 |
| --- | --- |
| 전용 비행 지도 사용 | 애드온 지도 사용 여부 |
| 대화창 없이 바로 지도 열기 | 조련사 대화창 건너뛰기 |
| 목적지 이름·요금·시간 표시 | 지도 위 이름표 표시 |
| 비행 지점 부분만 크게 보기 | 지점이 있는 영역 확대; 기본값은 꺼짐 |
| 미발견·미연결 비행 지점도 표시 | 현재 이용할 수 없는 지점 표시 |
| 세계 지도 그림 사용 | 지도 배경 변경; 기본값은 기본 비행 지도 |
| 창 크기·투명도·글자 크기 | 화면 표시 조절 |
| 비행 전 확인 창 표시 | 출발 전 목적지와 요금 확인 |
| 남은 비행 시간 막대 표시 | 비행 중 남은 시간 표시 |
| 도착 알림 | 도착 시 소리와 작업 표시줄 깜빡임 |

## 명령어

`/efm` 대신 `/easyflightmap` 또는 `/비행지도`를 사용할 수 있습니다.

| 명령어 | 동작 |
| --- | --- |
| `/efm` | 도움말과 현재 사용 상태 표시 |
| `/efm config` | 설정 창 열기 |
| `/efm on` · `/efm off` | 전용 지도 켜기·끄기 |
| `/efm skip` | 조련사 대화창 건너뛰기 전환 |
| `/efm labels` | 이름표 표시 전환 |
| `/efm crop` | 비행 지점 영역 확대 전환 |
| `/efm all` | 미발견·미연결 지점 표시 전환 |
| `/efm art` | 기본 비행 지도와 세계 지도 그림 전환 |
| `/efm scale 80` | 창 크기를 80%로 설정; 범위 50~120% |
| `/efm alpha 20` | 창 투명도를 20%로 설정; 범위 0~70% |
| `/efm bar` | 남은 시간 막대 표시 전환 |
| `/efm alert` | 도착 알림 전환 |
| `/efm reset` | 지도와 시간 막대 위치, 지도 크기 초기화 |
| `/efm donate` | 후원 주소 표시 |

`/efm reset`은 비행 시간 기록을 삭제하지 않습니다. 비행 전 확인 창은 설정 화면에서 변경합니다.

## 문제 해결

**지도가 잘리거나 글자가 너무 크다면** 창 크기와 글자 크기를 줄이고, **비행 지점 부분만 크게 보기**를 꺼보세요. 창이 화면 밖으로 이동했다면 `/efm reset`으로 위치를 초기화하세요.

**시간이 미측정이라면** 계산에 필요한 구간 정보가 없는 경로입니다. 비행을 완료하면 실제 시간이 기록됩니다.

**기본 지도로 확인하려면** 지도 창의 **기본 비행 지도로 보기** 버튼을 사용하거나 `/efm off`를 입력하세요.

**오류를 제보할 때는** 애드온 버전, 클라이언트 버전, 진영, 출발지·목적지, 오류 메시지와 화면 캡처를 함께 알려주세요.
